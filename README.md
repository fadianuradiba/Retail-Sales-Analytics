# Retail Sales Analytics

## Project Overview

This project focuses on analyzing retail sales performance using Microsoft Excel and transaction data from DQLab's Fashion Dataset. The analysis explores sales trends, product performance, branch performance, and customer purchasing behaviour to identify business insights and support data-driven decision-making.

## Business Objectives

- Understand overall sales performance and revenue trends.
- Identify high-performing and low-performing products.
- Evaluate sales performance across different branches.
- Analyze customer purchasing behaviour and transaction patterns.
- Provide actionable recommendations to improve business performance.

## Dashboard Pages

1. **Overview** — presents overall sales performance, key metrics, and revenue trends.
2. **Sales Analysis** — explores sales performance over time, monthly revenue trends, and transaction patterns.
3. **Product Analysis** — examines product performance and revenue contribution.
4. **Branch Analysis** — compares sales and revenue performance across different branches.
5. **Behaviour Analysis** — analyzes customer purchasing patterns, transaction characteristics, and buying behaviour.

## Key Deliverables

- Interactive Excel dashboard
